Definición informal de orden 

Asi que odemos definir el orden si existen dos funciones 
$t_1(n)~y~t_2(n)$

que cumplan que 

$c_1\leq \frac{t_1(n)}{t_2(n)} \leq c_2$

para esto usaremos el conc epto de poder diferenciar las instrucciones y de poder ver la parte matematica para poder definir uno u otro, para ello podemos usar estos simbolos:

- Orden superior: $O(t(n))$
- Orden inferior: $\Omega(t(n))$
- Orden estricto: $\Theta(t(n))$

la idea se basa en buscar la forma de resolver un problema usand el minimo tiempo posible,  y para ello aprenderemos unas cuantas herramientas matematicas, de las cuales obterndremos los datos.
