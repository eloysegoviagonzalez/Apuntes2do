Criterios de planificación de la CPU

Primero tenemos que ver que hay disntintos tiempos sobre los que optimizar, para el usuario el tiempo:
- Tiempo de espera: el tiempo que pasa el proceso en la cola de listos
- Tiempo de respuesta: el tiempo que pasa  desde que el proceso entra al sistema hasta que toma la CPU por primera vez
- Tiempo de retorno: Tiempo total que transcurre desde que el proceso entra el sistema hasta que termna ell proceso
- Tiempo de retorno normalizado: este se define matematicamente usando esta formula
$$ \frac{Tiempo~de~retorno}{Tiempo~de~servicio}$$
