|                              | Solo una secuencia de instrucciones                | Multiple secuencias de instrucciones                                                                                   |
| ---------------------------- | -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Una sola secuencia de datos  | SISD: procesadores historicos y microcontroladores | MISD: Sistemas criticos, usado en muy pocas ocasiones y se comenta de forma teorica como tipo que no existe realmente. |
| Multiple secuencias de datos | SIMD: DLP, con paralelismo a nivel de datos        | MIMD: PLP, con el paralalelismo con instucciones y datos                                                               |
