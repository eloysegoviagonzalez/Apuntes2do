Manejo de puertos por usuario

para poder manejar y ver que hace el dispositivo por parte del usuario se usan comandos como `netstat`, podemos ver que existe una figura especializada llamada **socket**, esta se define como:

`IP:PUERTO`

estos son manejados por el sistema operativo de tal forma en la que el sistema operativo es capaz de abrir un puerto por proceso, o por protocolo si es servidor,de tal forma en la que se crea un canal directo.

por ejemplo los buscadores usan puertos dinamicos para servicios relacionados con los clientes, lo que permite canalizar la comunicación de forma distinguible a nivel de dispositivo y proceso con el **socket**.
