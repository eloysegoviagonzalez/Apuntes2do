Según su protección

El cable de par trenzado es muy variable, pero normalmmente hay tres tipos:

- # UTP
Este es un cable con cuatro pares de hilos que no tiene protección anti-interferencias, estos hilos se agrupan en cuatro pares.

El conector que suelen usar es el conector RJ-45, con longitud maxima de 100m.

- # S/FTP
Este se caracteriza por tener protecciones anti-interferencias, con apantallamiento exterior (S/), una malla metalica,e interior (/F), con lamina de aluminio para cada par, sigue siendo un sistema de cuatro pares. 

Suelen usar los conectores QG45,TERA, con longitud maxima de 100m

- # SF/UTP
Este se caracteriza por tener toda su protección exterior , con apantallamiento y llama metalica exterior, sigue siendo un sistema de cuatro pares.

Usan conectores QC45 o TERA, con longitud maxima de 100m
