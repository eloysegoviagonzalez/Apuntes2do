# Valoracion y selección de  proyectos de inversión
Unos cuantos, basicos son:
|                        | Elementos de una inversión                     |
| ---------------------- | ---------------------------------------------- |
| Desembolso inicial $A$ | El dinero que se aporta en el momento incia    |
| Tiempo $n$             | El tiempo que se espera de tener una inversión |
| Capitalización %C%     | La proyección del valor de la inversión        |

Esto por ejemplo nos ayuda para comparar el capital respe to al tiempo a traves de la capitalización dinamica tal que:
$$C_n=C_i(1+k)^n$$
donde $C_ n$ es la capitalización actual y $C_i$ la inicial
