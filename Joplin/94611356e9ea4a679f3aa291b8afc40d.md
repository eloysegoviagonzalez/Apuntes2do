esto significa que podemos tener instrucciones maquina que permiten hacer operaciones vectoriales, pudiendo hacer varias veces la misma operación de una sola pasada, siendo una unica instrucción vectorial.

Para eso el compilador debe hacer dos cosas:
- si el bucle es paralelizable, osea si se puede considerar que tecnicamente se hacen lo mismo con distintos datos.
- entonces encargarse de la paralezización de forma correcta.

Además para que un procesador sea SIMD, necesitamos incorporar además de varias ALUs, instrucciones SIMD.
