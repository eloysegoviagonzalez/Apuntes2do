Elementos Conceptuales de la empresa como sistema

Segun Bueno, Cruz y Duran la empresa se puede definir como un conjunto de elementos ordenados en una estructura organizativa.

Estas tiene unos elemntos basicos como:

1. Conjunto de elementos: Factores humanos y tecnicos combinados en diferentes centros o unidades de gestion (trabajadores, directivos, bienes,etc)
2. Estructura del sistema: Orden dado a los elementos segun el modo de estructura organizativa
3. Plan común: Conjunto de objetivos planeados por la empresa
4. Funciones caracteristicas: estas son las necesarias para que las empresas sean capaces de desarrollar as actividades necesarias para llevar a cabo el plan comun
5. Conjunto de estados: El conjunto de estados necesarios para que la empresa funcione
