Concepto y Propiedades de los Sistemas

Como tal introducimos el termino  de sistema. Un sistema en terminos empresariales se define como un conjunto de objetos los cuales se interrelacionan, segun Durán economicamente se puede determinar como un conjunto de objetos con cierta estructura y relaciones con funciones determinadas para lograr objetivos determinados.

los principios generales son:
1. Interrelación: el grado de interdependencia en parametros como objetivos, elementos, atributos o acontecimientos
2. Totalidad: La teoria de sistemas es un ntento de analizar el todo. incluyendo sus iterrelaciones
3. Busqueda de metas: Este engloba los componentes interrelacionales
4. Input-Ouput: El sistema depende de entregar un conjunto de entradas para devolver una serie de salidas
5. Transormación: todo sistema transforma las entradas en salidas como proceso
6. Entropia: el sistema no funciona en el desorden
7. Negentropia: la reducción del desorden
8. Regulación: Implantar un sistema de control
9. Diferencacion: Es necesario diferenciar la actuación de las partes segun sea necesario
10. Jerarquia: Es necesario que las distintas partes actuen en un sistema con una cierta jerarquia
11. Equifinalidad: Es necesario que todo el sistema, pueda tener un conjunto de fines definidos en su conjunto
