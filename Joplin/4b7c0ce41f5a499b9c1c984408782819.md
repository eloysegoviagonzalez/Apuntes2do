Paralelismo Subword

El paralelismo subword es un tipo de paralelismo especial que usa registros y ALUs con una dimension de registros Y ALU mayor a la palabra de la arquitectura, por ejemplo 64 bits. Esto permite ejecutar varias operaciones a la vez.

# MMX(MultiMedia eXtension)
El primer conjunto de extension de instrucciones,del año 1997, donde los registros vectoriales son de 64 bits y pensado para arquitecturas de 32 y 16 bits, con palabras de 16 bits. 

Estas usaban instruciones tales que 
```
PADDQ // Cuatriple plabara /64 bits
PADDD // Doble palabra /32 bits
PADDW // Palabra /16 bits
PADDB // Byte /8 bits
```
pudiendo usarse con registros vectoriales
```
PADDW mm1, mm2
``````
# SSE2
Equivalente mas modernos,con 128 bits, aun con palabras de 16 bits, del año 2000

```
PADDQ // Cuatriple plabara /64 bits
PADDD // Doble palabra /32 bits
PADDW // Palabra /16 bits
PADDB // Byte /8 bits
```

Este se puede usar tal que 
```
PADDW xmm1, xmm2
```

# AVX

Este es el mas moderno, de 2011, en palabras de 32 bits y con extension de 256 bits:

```
VADDPD // Doble plabara /64 bits
VADDPS // palabra /32 bits
```

un ejemplo seria:

```
VADDPD ymm1,ymm2,ymm3
```
