Tres métodos directos de ordenación 

# Burbuja(intercambio directo)
Este podemos ver que se comporta tal que así:
```
void bubbleSort(std::vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        // Los últimos i elementos ya están ordenados
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                std::swap(arr[j], arr[j + 1]);
            }
        }
    }
}
```
intercambiando los elementos en pareja

Este como tal no tiene ni mejor ni peor caso y está en el orden de $O(n)$
# Selección
Este se ve como esto:
```
void selectionSort(std::vector<int>& arr) {
    int n = arr.size();
    
    for (int i = 0; i < n - 1; i++) {
        int indiceMin = i;   // Suponemos que el mínimo está en i
        
        // Buscar el mínimo en el resto del array
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[indiceMin]) {
                indiceMin = j;
            }
        }
        
        // Intercambiar el mínimo encontrado con la posición i
        if (indiceMin != i) {
            std::swap(arr[i], arr[indiceMin]);
        }
    }
}
```

Tampoco tiene ni mejor ni peor caso , y sigue teniendo el mismo orden de $O(n)$ que el metodo de burbuja.
# Inserción 
Este podemos ver que es un tanto difrente
```
void insertionSort(std::vector<int>& arr) {
    int n = arr.size();
    
    for (int i = 1; i < n; i++) {
        int clave = arr[i];      // Elemento a insertar
        int j = i - 1;
        
        // Mover los elementos mayores que 'clave' una posición adelante
        while (j >= 0 && arr[j] > clave) {
            arr[j + 1] = arr[j];
            j--;
        }
        
        // Insertar la clave en su posición correcta
        arr[j + 1] = clave;
    }
}
```

Este es mas interesante, ya que tiene un mejor y un peor caso definidos como $O(n)$ en una lista ordenada, y $O(n^2)$ en una lista inversamente ordenada
