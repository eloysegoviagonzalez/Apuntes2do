Perturbaciones en medios de cobres

- # Ruido
Las señales en medios de cobre son vulnerables a la adicion de señales no deseadas denominadas como "ruido", este puede sumarse al mensaje original y alterar el mensaje
  - ## Interferencia Electromagnética
	Estas son de origen externo, de parte de motores, generadores, calentadores , iluminacion fluorescente o cualquier cosa que genere electricidad de forma no estadar.
  - ## Diafonia
	El ruido de origen interno del cable.
- # Atenuación
 el hecho de que la señal puede ir perdiendo potencia con el tiempo.

Se pueden paliar de distintas maneras:

| Medidas                            | Ruido electrico | Diafonia | Atenuación |
| ---------------------------------- | --------------- | -------- | ---------- |
| Blindaje en cada par               | Si              | Si       | No         |
| Blindaje global                    | Si              | Si       | No         |
| Separador de pares                 | No              | Si       | No         |
| Terminacion de conectores adecuada | Si              | Si       | No         |
| Trenzado                           | Si              | Si       | No         |
| Señales diferenciales              | Si              | Si       | No         |
| Limites de longitud                | No              | No       | SI         |
