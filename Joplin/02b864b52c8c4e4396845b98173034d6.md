Evolución historica

# Primeros sistemas
Los primeros sistemas de computadores no disponian de un sistema operativo como los conocemos, ni tampoco existiendo los lenguajes de pogramación de alto nivel, con un esquema monoprograma y monousuario interactivo, siendo sistemas interactivos, caros y con unico obetivo de perseguir el rendmiento, apareciendo los manejadores de dispositivos y los compiladores.

# Sistemas por lotes
Su nombre viene de que el trabajo se asignaba en espacios denominado lotes, donde se cargaba una vez uno y luego otro.

Esto permitio ahorrar tiempo, ademas de iniciar la figura del operador, esto permitio que los sistemas dejaran de ser interactivos, pese a que aun fueran monoprogramados. Esto también dio lugar a los secuenciadores de trabajos automaticos, siendo denominados monitores residentes, los primeros sistemas operativos.

Además, surgieron tecnicas para solapar operaciones de E/S, como el buffering y el spooling.

# Sistemas por lotes multiprogramados 
Aqui podemos ver que, los sistemas por lotes, al obtener mas memoria, empezaron a ser capaces de coexistir varios procesos en memoria y a necesitar mecanismos de protección de memoria, eso significa que cuando un trabajo necesite realizar una operacion de E/S, otro pueda escoger otro para su operacion.

Además existen los planeadores de procesos

# Sistemas de tiempo compartido
Ya, aqui podemos tener sistemas multiprograma y multiusuario interactivos, usando dispositivos de terminal, donde la CPU debe atender a todas las peticiones de usuario por turnos y dedicando un tiempo a cada uno de ellos

# Otros tipos de sistemas
## Sistemas para Ordenadores personales
Surgen con hardware mas barato, perdiendo caracteristicas de SOs avanzados al inicio
## Sistemas de tiempo real
Son sistemas con requisitos estrictos de tiempo, para sistemas embebidos, como sistemas de control de fabrica
## Sistemas distribuidos
Sistemas entre varios ordenadores 
# Necesidades
los sistemas operativos han ido cqambiando sus necesidades, pero entre ellas siempre han sido:
- Mejorar el rendimiento usando la compartición de recursos, aunque necesite recursos para proteger al sistema 
- Proteger al sistema usando herramientas como el bit de modo, introduciendo el modo de usuario y el modo nucleo, creando el modo dual de ejecución, donde el usuario no tiene acceso a aquellas instrucciones que sean privileigiadas, ademas de usar otras herramientas como registros limites,temporizadores, aunque los dispositivos de E/S no lo necesiten al ser "privilegiados".
