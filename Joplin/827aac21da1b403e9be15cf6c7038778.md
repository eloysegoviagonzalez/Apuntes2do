Funciones de un Sistema operativo


Un  sistema operativo tiene dos funciones principales, la solicitud de servicios  y crear procesos 

# Solicitud de servicios
El sistema operativo se encarga de manejar sus funciones en forma de servicios, ya sean llamadas al sistema o de paso de mensajes, dependiendo de la estructura interna de un sistema operativo. 

Esto hace que el usuario hace peticiones al sistema, el kernel determina el servicio necesario y lo ejecuta, devolviendo la información necesitaria, o de pasar la información de forma interna.

# Crear Procesos 
Son aplicaciones del sistema que, de forma mas dinamica, son capaces de dar información através del paso de mensajes
