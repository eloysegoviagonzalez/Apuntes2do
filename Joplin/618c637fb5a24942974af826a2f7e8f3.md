Introducción 

los puertos son numeros de 16 bits que identifican a los procesos de red, tal que:

| TIPOS         | RANGO       | EJEMPLOS DE USO                                  | ASIGNACIÓN |
| ------------- | ----------- | ------------------------------------------------ | ---------- |
| Bien conocido | 1-1023      | protocolos ej: HTTP(80)o o FTP(21)               | estática   |
| Registrado    | 1024-49151  | aplicaciones ej:gnutella(5795) o xbox live(3074) | estática   |
| Dinámicos     | 49151-65535 | procesos cliente                                 | dinámica   |

 los puertos mas basicos son:

| Puerto | Protocolo | Uso                                |
| ------ | --------- | ---------------------------------- |
| 20,21  | FTP       | Transferencia archivos             |
| 23     | Telnet    | Conectar a terminales(es inseguro) |
| 25     | SMTP      | Correo electronico                 |
| 53     | DNS       | Enrutar IP                         |
| 80     | HTTP      | Webs                               |
| 110    | POP3      | Correo electronico                 |
| 443    | HTTPS     | Web segurao                        |
