Introducción

Los procesadores pueden tener un juegos de instrucciones, especialmente en arquitecturas CISC como x86-64, a las cuales se les añaden varias mas, por ejemplo en x86 existen de base:
- x86-64 (AMD)
- AMD64 (AMD)
- IA32e (Intel)
- EM64T(intel)
- Intel64(intel)

A las cuales se les puede añadir otras mas como extensiones, para varias tareas como criptografia, ejecución de software multihilo o virtualización, pero la principal es para paralelismo con SIMD, con extensiones como MMX para el paralelismo.
