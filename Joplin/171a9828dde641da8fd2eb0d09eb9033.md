# Creación de procesos
Aqui se le da varios atributos como un PID, un espacio de direcciones predeterminado a medida de las necesidades del proceso, inicializar un bloque de control al proceso donde este su información basica, introducirlo en la cola de procesos y crear otras estructuras de datos necesarias
# Cambio Contexto
Cuando el  proceso simplemente cambia el contexto de un proceso, el sistema operativo ha de guardar en la pila el estado actual para poder recargarlos antes de seguir el proceso despues.

Es util para cambios rapidos como operaciones de E/S de terminal o excepciones.
# Cambio de Procesos
Se guarda el contexto del proceso de ejecución en la pila del proceso y despues iniciar o reiniciar otro contexto con los datos guardados en la pila del proceso, cargando el proceso sigueinte.

Al ser similar al cambio de contexto simple, pero mas costoso y radical que el cambio de contexto, es util para entornos  donde se necesita mas tiempo,como para operaciones lentas entre programas.
