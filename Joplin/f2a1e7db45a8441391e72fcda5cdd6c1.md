PRESTACIONES


| Concepto | Fórmulas |
| :--- | :--- |
| **Tiempo de CPU** | $T_{\text{CPU}} = \text{NI} \times \text{CPI}_{\text{global}} \times T = \dfrac{\text{NI} \times \text{CPI}_{\text{global}}}{F}$<br><br>$T_{\text{CPU}} = \text{CPP} \times T = \dfrac{\text{CPP}}{F}$ |
| **MIPS y MFLOPS** | $\text{MIPS} = \dfrac{\text{NI}}{T_{\text{CPU}} \times 10^6} = \dfrac{F}{\text{CPI}_{\text{global}} \times 10^6}$<br><br>$\text{MFLOPS} = \dfrac{\text{NI}_{\text{flotantes}}}{T_{\text{CPU}} \times 10^6}$ |
| **Prestaciones** | $\text{Prestaciones} = \dfrac{1}{T_{\text{CPU}}}$<br><br>$\dfrac{\text{Prestaciones}_A}{\text{Prestaciones}_B} = \dfrac{T_{\text{CPU},B}}{T_{\text{CPU},A}} = n$ |
| **Ley de Amdahl** | $\text{Incremento del rendimiento} = \dfrac{\text{Tiempo sin mejora}}{\text{Tiempo con mejora}} = \dfrac{1}{(1 - F_m) + \dfrac{F_m}{M}}$ |

**Terminos:**
 - $F_m$: fracción del tiempo de ejecución que se beneficia de la mejora[cite: 1].
- $M$: factor de mejora[cite: 1].
