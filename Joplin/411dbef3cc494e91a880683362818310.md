¿Que es un sistema operativo?

Primero, tenemos que partir del software y del hardware, dentro del software existen los programas del sistema y los programas de aplicación. Dentro del software del sistema, entre varios programas como compiladores, editores e interpretes, existe el sistema operativo en si, el nucleo.

El nucleo, como sistema operativo, se ejecuta en modo de supervisor, de mientras que todo lo demas corre en modo de usuario, esto es debido a que el sistema operativo necesita hacer dos cosas:

- Administrar recursos
- Abstraer el hardware
