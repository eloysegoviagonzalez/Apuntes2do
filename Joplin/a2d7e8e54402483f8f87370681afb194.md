El entorno empresarial

El entorno empresarial se define por lo que rodea al conjunto empresarial, estos, normalmente son muy variados y marcados por las interacciones que tienen. Para esto es necesario la capacidad de filtrar estas, al ser sistemas semicerrados y tomar decisiones basados en lo filtrado. 

Segun **Kast y Ronsenzweig**(1979) se puede distinguir entre:

| ---------- | ------------ |
| Cultura    | Consumidores |
| Tecnología | Proveedores  |
| Politica   | Competidores |
| Leyes      | RRHH         |
| Demografia |              |
| Economía   |              |
