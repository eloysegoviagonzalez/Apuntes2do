Elementos físicos de una red cableada

# Racks:
   armarios especializados para contener elementos de red, pueden diferenciarse según su rol, como el de planta, edificio o el principal, el cual actua como Rack de planta y Rackde edificio y se le denomina Rack de Campo.

Deben estar correctamente etiquietados
# Toma de comunicaciones:
  tomas de pared espeficiaas para conectar elementos de red, con tipos variados como DAC o Rossettas y deben estar correctamente identificadas y por lo menos existir dos, por ejemplo para un cliente y un telefono VOIP.
# Paneles de conexión:
  elementos especialidados compuestos de muchas tomas para poder controlar distintas tomas del sistema, con cada una de estas tomas con etiqueta propia.
# RAC:
  son cajones especialicados dentro de los Rackss  con tornilos, se miden en $u$ que es equivalente a tres orificios de los rieles del Rack, y tambien los dispositivos que se van a instalar en el Racl, se pueden diferenciar en varios tipos segun dispositivo.
