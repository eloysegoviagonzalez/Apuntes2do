Explicación y calculo para transvase de cache a memoria

n cambio, el paso de memoria de la cache depende de tener la posicion bien puesta( indice y etiqueta) en forma de palabras separadas por cada byte que contiene el bloque, podremos separar la dirección de palabras de esta forma:

| Etiqueta            | Indice              | Dirección de palabra |
| ------------------- | ------------------- | -------------------- |
| Dirección de bloque | Dirección de bloque | Dirección de palabra |

para su calculo se recomienda usar  estas formulas:

$$Tamaño~etiqueta=m-n-BLOCKoffset-BYTEOffset$$

donde $m$ son los bits del bus de direcciones $n$ los bits del indice $BLOCKoffset$ los bits necesarios para identificar una palabra dentro de un bloque  y $BYTEoffset$ los bits necesarios para identificar un byte  dentro de una palabra
y tambien
$$Dirección~Bloques=\frac{Dirección~Byte}{Nº~Bytes~del~bloque}$$
