Inversiones

Toda inversion se define como una parte del patrimonio que esta sujeta a depreciación, esto se puede definir facilmente usando el tiempo, por lo que podemos tratar las inversiones como si fueran un tipo de gasto que se va extendiendo un numero, digamos $n$ de años, asi que con un "gasto" $G$ y una inversión $I$ vemos que 

$$G=\frac{I}{n}$$

A $G$ se le puede denomina tambien  AAIM, y suele ponerse en el balance de perdidas y ganancias como perdida anual "inmobilizada", en este caso en el ajuste de balamces se puede ver como:


| ACTIVO                                       | PASIVO                                    |
| -------------------------------------------- | ----------------------------------------- |
| Inversión $I$ (+)                            | Beneficios considerando el gasto $B_G$(+) |
| "Gasto" AATM $G$ (-)(acumulado con los años) |                                           |

para esto, tambien hay que comentar que el AAIM se le considera como una esperanza de vida media por lo que la inversión puede durar mas tiempo o puede siniestrarse, en el caso de siniestro la contabilidad  se efectua como si fuera un gsto de $I-Gk$ donde $K$ es la cantidad de años
