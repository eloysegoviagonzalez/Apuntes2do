Según sus terminaciones


| Tipo de cable      | Terminaciones          | Aplicación                                                                     |
| ------------------ | ---------------------- | ------------------------------------------------------------------------------ |
| Directo            | 568A-568A o 568B-568B  | Dispositivos distintos(excepto PC-Router)                                      |
| Cruzado            | 568A-568B              | Dispositivos equivalentes o PC-Router                                          |
| Tranpuesto/Consola | 568A-568A o  568B-568B | Consola de equipos de red como router o switches, para control de dispositivos |

La forma de diferenciar el 586A del 568B es diferenciar los colores es esta:
![1d1e0b309dbcc4e5e5166babbc91c00a.png](:/3d8eae8fc5d749be91d38a3c4491304e)

Esta diferenciación viene al hecho de que para comunicar sistemas con el mismo rol hay que intercambiar las transmisiones y recepciones de datos, mientras que al seguir en distinto rol los puertos se mantienen estables.

Es importante comentar que en caso de terner terminaciones inadecuadas podrian haber problemas de velocidad
