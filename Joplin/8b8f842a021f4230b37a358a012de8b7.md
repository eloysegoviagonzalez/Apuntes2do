Vida de un proceso

##  Modelo de 5 estados
Un proceso tiene una vida desde que se crea hasta que se elimina, teniendo cada SO  una forma de organizarlo, los SO normalmente tienen cinco estados, tal que:
![ec8210f902af46b754b8833bd8f9cba6.png](:/f1eb43ef43d842d08f1ce444d3f19206)
Podemos ver que como tal en esos cinco estados hay cinco etapas:
- Nuevo: aqui al proceso se crea y se le da el contexto necesario y se le asigna la memoria necesaria, pasa a listo normalmente via Admisión.
- Terminado: aqui el proceso se le libera la memoria y se destruyen las estructura de proceso
- Listo: preparado para ejecutarse pero sin aun estar ejecutandose,ya sea por su inicio o porque se despierta el proceso de bloqueo, puede pasar a ejecución en cualquier momento
- Ejecución: como tal es en la que el proceso es capaz de funcionar, puede pasar a terminado, a listo por apropiación o a estar bloqueado 
- Bloqueado: El proceso en este estado esta esperando a seguir su ejecución por algun dato que requiera intervención de usuario o que aun no este disponible

## Implementación
Normalmente esta implementacion se hace usando colas de procesos donde a los procesos,
![fd1770d1949ec10a7f13182a3d16c980.png](:/25d41b8a98b44879b5c879faa6669adc)
donde la cola de listos  tiene que estar ordenada segun sea conveniente para la eficiencia, y la cola de bloqueados no lo suele estar. 

en los sistemas opertativos modernos se usa una cantidad de $n$ colas segun haya $n$ procesos  ya que aumenta la eficiencia para buscar procesos

# Modelo complejo
Aqui metemos un estado mas que es un estado  de
- Suspendido: como tal es un estado bloqueado el tal es bloqueado por un agente externo, por ejemplo en una compilación una depuración.
  ![3891c66e393a6a0de7acd4e65b058383.png](:/e7d05a7db9a648c180f77a3d362e133a)

Esto es util para muchas cosas como parar procesos en caso de que falte memoria, cuando el usuario desee o similares, puediendo  estar listo en suspension, si es suspendido de ejecución o estando listo,  o bloqueado si es suspendido en un estado bloqueado, además un proceso suspendido bloqueado puede ser despertado a estar suspendido listo y volverse listo en ese estado via activación o incluso el usuario o procesos independientes pueden activar un proceso bloqueado que este suspendido, pero no el SO.

Similarmente, en casos extremos el usuario puede terminar cualquier proceso si es necesario en cualquier etapa.
