# Activos 
| Activo corriente                        | Activo no corriente                       |
| --------------------------------------- | ----------------------------------------- |
| Existencias                             | Inmobilizable                             |
| Realizable c/p(futuras ganancias a c/p) | Realizable I/p(futuras existencias a l/p) |
| Disponible en caja                      |                                           |

- **l/p** y **c/p** son a largo plazo, mas de un año, y a corto plazo, menos de un año,


Siendo los mas liquidos los activos corrientes, y los menos liquidos el inmobizable, tam.
